# EndNote citation downloads

Six_Leiden_maps_APA7.enw contains all six maps: four descriptor viewers and two manual tension viewers. Four_Leiden_maps_APA7.enw retains the original four descriptor records.

In EndNote, import with the EndNote Import filter and select APA 7th as the output style. The ENW file stores metadata; EndNote applies the formatting. The researcher is Martin Schmalzried. The year is 2026; descriptor interfaces are Version 3 and tension interfaces are Version 1. Keep Year as 2026 and let EndNote generate the required same-author/year letters in the final bibliography. Importing the six-record file after importing the original four can create duplicates; use EndNote's duplicate review as needed.

These self-contained interactive visualisation tools use the Computer Program reference type and the APA bracket description [Computer software]. Direct viewer URLs are included. The tension records identify tension_content as their network field and record the exact source-viewer SHA-256.
