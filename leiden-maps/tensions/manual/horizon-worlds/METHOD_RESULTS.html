Source-label interpretation

All non-empty tension_content labels are retained literally. Horizon Worlds includes positive_feedback in this field, so membership in the field alone does not establish that a label denotes a substantive conflict. Review source messages before interpreting those labels; no additional recoding was performed.

Reading the Horizon Worlds boundaries

The default shared-topic tension graph has Q=0.681 and median bootstrap ARI=0.422. It is more separated than the Decentraland default graph, while community membership remains sensitive to resampling. This does not establish interpretive theme validity or permit a direct equivalence between the two code vocabularies.
